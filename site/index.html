About WeatherPower

WeatherPower Live is a passion project from Idabel, Oklahoma, built by one person who loves weather. WeBot reads real NWS alerts, real radar and real forecasts, and the whole thing runs on an $11 server and open-source code.

It is not a Ryan Hall, Y'all copy and isn't trying to be. If you like it, the best support is watching, chatting, and sharing.
