OBS setup

  1. In OBS: Sources → + → Browser, name it “WeatherPower Overlay”.
  2. URL http://localhost:7788/overlay Width 1920, Height 1080. Tick Control audio via OBS.
  3. Put it at the top of your scene, above your camera, screen or radar.
  4. Leave Stream House running while you’re live (its black window).
