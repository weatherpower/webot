      Picture quality
      
            
      
            
      The map is drawn without a graphics card, so resolution costs a lot of CPU. On the current 4-core plan, 720p is the safe maximum; 1080p needs the 8-core plan (and Stream CPUs set to 6).

      Help
      
        
      
          
      Starting Studio
      
          
      Double-click WeBot Studio on your desktop or open it from the Start menu (WeatherPower folder). It is its own program window; close it to stop Studio. The stream keeps running either way. If the program ever goes missing, run npm run build in the project's desktop folder to put it back (the old studio\WeBot Studio.cmd still works too and opens Studio in your browser).
      
          
      Changing what WeBot says and does
      
          
      Use Brain. Lines with {city} or {name} get the city or viewer’s name filled in. Segment weights decide how often each one comes up on calm days (0 turns it off). Press Save to stream: the stream picks it up within seconds. Reset all to defaults puts everything back the way it was built.
      
          
      Live show buttons
      
          
      The Overview’s Show control does the same as Live Control: skip, BRB, talk on/off, radio style, make WeBot say something.
      
          
      Picture quality and keys
      
          
      Server holds the stream settings (resolution, bitrate, YouTube keys). Save, then Restart stream. Every save keeps a backup of the old settings on the server (.env.bak-…, last 10).
      
          
      Editing code
      
          
        
            
      1. Open Code, pick a file, edit, press Ctrl+S. Studio checks it for mistakes and keeps a backup in studio\.backups.
        2. 
            
      2. Press Save version with a short note (this is a git commit, so you can always go back).
        3. 
            
      3. Press Deploy to server. Page-only changes go live with a quick page reload; anything else rebuilds the stream (about 1–2 minutes off air).
        4. 
          
      
          
      Broke something? In Code, Undo my changes puts a file back to the last saved version. To go back further, use History and deploy again.
      
          
      If the stream looks wrong
      
          
        
            
      • Map blank or frozen: Reload stream page.
        • 
            
      • Sound sputtering: run Checks → Audio; if CPU is near its limit, lower the quality in Server.
        • 
            
      • Nothing works: Restart stream. Then check Logs → Problems.
        • 
            
      • Studio can’t connect: your home internet address may have changed. Add it on the server page from another network’s SSH, or ask for help.
