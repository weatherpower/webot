Install on your main PC

Your WeatherPower control room, on this computer.

Install the full desktop WeBot Studio checkout with one Windows installer. It sets up the tools Studio needs, signs into the private WeatherPower GitHub repository, creates shortcuts, and launches Studio at localhost:7777.

Download Windows installer View WeBot status
Install location: %LOCALAPPDATA%\WeatherPower\WeBot Studio
This is an owner-only installer. Because the WeBot repository is private, GitHub will ask you to sign in with an account that has access to weatherpower/webot. The installer does not contain a GitHub token or controller token.
What the installer does
01 Check Git, GitHub CLI and Node.js
02 Install anything missing with winget
03 Sign in to GitHub in your browser
04 Clone the private WeBot master branch
05 Install the lightweight Studio runtime
06 Create Desktop + Start Menu shortcuts
07 Launch WeBot Studio
READY · future Studio updates still use the real Git checkout

Three steps and you're in

The installer is designed for a clean Windows 10/11 machine, so you don't have to manually rebuild the setup you have on the development PC.

1
Download

Grab Install-WeBot-Studio.cmd from the button above and open it.

2
Sign into GitHub

If needed, the installer opens GitHub's browser sign-in. Use the WeatherPower account that can access the private repo.

3
Launch Studio

A WeBot Studio shortcut is added to your Desktop and Start Menu, and the installer opens it when setup finishes.

Safe existing-install behaviorIf a real WeBot Git checkout already exists, the installer only attempts a fast-forward update. It will not hard-reset or delete local changes.
